# مدار الملفات — MadarFiles Web

مصدر نسخة ويب أعيد بناؤها بناءً على المتطلبات والتصحيحات السابقة. هذه إعادة بناء جديدة، وليست نسخة مطابقة بايتًا للالتزام السابق 3127c1f. الموقع المنشور سابقًا على Netlify لا يتغير تلقائيًا بإضافة هذا المستودع؛ يلزم ربطه أو نشر هذه النسخة صراحةً.

## التشغيل

Node 24 وPython 3.12 للاختبارات، وFFmpeg لاختبارات الوسائط. بناء الواجهة لا يحتاج Google أو GPU.

~~~bash
npm install
npm run build
npm run check
node --test --test-concurrency=1 tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py' -v
npx netlify-cli@27.19.0 dev
~~~

الناتج الثابت في dist، وخادم Netlify خارج مجلد النشر في netlify/functions. البناء يولد generated/worker.mjs من colab/worker.py ويضمّن خطوط أميري من التزام مثبت في Google Fonts. لا تعدّل generated يدويًا.

## الأدوات

- تعديل الصور وصيغها ومقاساتها وتدويرها وعكسها، صور إلى PDF، دمج وترتيب واستخراج وتدوير صفحات PDF، استخراج صور الصفحات والنص المضمن.
- تعديل الصوت محليًا: قص وقوة الصوت والسرعة والعكس مع WAV حقيقي؛ تحويل محلي عبر FFmpeg.wasm، حذف الصوت كله، حفظ لقطة PNG، تعديل SRT وQR للنص والرابط.
- تصميم اسم عربي: 20 إطارًا مختلفًا، 30 لون تصميم و15 لون خط.
- فصل الموسيقى في حساب Colab للزائر مع أجزاء محفوظة وبصمات تحقق وتقدير وقت مبني على سرعة الأجزاء المنجزة.
- أربعة أوضاع موحدة: تفريغ، تفريغ وترجمة، تفريغ وكتابة على الفيديو، تفريغ وترجمة وكتابة على الفيديو. الأوضاع الصوتية تستخدم الخيارين الأولين.
- معاينة ثابتة من الفيديو، سحب النص والشعار، موضع وحجم ولون ونوع ووزن الخط. حرق SRT جاهز أو ملفات التفريغ الناتجة.
- ترجمة النص وSRT عبر Colab أو Groq بمفتاح الزائر، مع حفظ الأصل والتوقيت والترجمة.
- تحويل سحابي وتغيير المقاس بالقص أو الضبابية أو التمديد الحقيقي بقوة قابلة للتعديل ومعاينة.
- OCR عربي/إنجليزي، عزل الخلفية، PDF إلى Word، تحميل روابط عامة، توليد صورة وفيديو صامت مع فحص النتيجة قبل التسليم.
- QR لملف في حساب Drive بعد موافقة المشاركة الصريحة.
- معاينة النتائج ثم الحفظ باسم المصدر ووصف العملية. قوالب التنسيق والمفضلة، وشريط الأدوات الحديثة يتحرك ويتوقف ثانيتين عند اللمس.
- Colab عبر API Google الأصلي وWebSocket آمن دون نفق عام أو استخدام حساب المالك للزوار.

## الصيغ والحدود

| المسار | الفيديو | الصوت |
| --- | --- | --- |
| Colab | MP4، MKV، MOV، WebM/VP9، AVI، MPEG-TS | MP3، M4A/AAC، WAV، FLAC، OGG/Vorbis، Opus، AAC |
| محلي | MP4، MKV، MOV، AVI، MPEG-TS | MP3، M4A، WAV، FLAC، OGG، AAC |

المحلي لا يعرض Opus وWebM لأنهما تعثرا في فحوص محرك المتصفح السابقة. الامتداد مثل MKV أو MP4 حاوية لا تضمن كل ترميز داخلها. لا تعيد WAV أو FLAC جودة مفقودة من المصدر.

حد المصدر السحابي 512 MB والنتيجة 256 MB؛ المحلي 80 MB؛ Drive 64 MB. WAV/FLAC قد يتجاوزان حد النتيجة؛ اختر صيغة مضغوطة أو جزءًا أقصر. دعم المصدر يعتمد على المحرك وسلامة الملف.

## Google

متغيرا Functions الاختياريان:
- GOOGLE_OAUTH_CLIENT_ID
- GOOGLE_CLOUD_PROJECT

معرف العميل ومعرف المشروع ليسا أسرارًا. أضف أصل الاستضافة إلى Authorized JavaScript origins، وفعّل Colab API وDrive API عند استخدام أدواتهما. يجب أن تكون الحسابات مخولة وفق حالة OAuth وأن تكون موارد Colab متاحة للحساب المتصل. صلاحية Colab منفصلة عن Drive ولا تُجمع تلقائيًا.

لا تضع تصريح ya29 أو مفتاح Groq أو Service Account في المستودع. رموز الزائر تبقى بذاكرة الصفحة وتُرسل إلى الوسيط ثم المزود المعني. Google يفرض ملكية المورد، والتجزئة مجرد مفتاح عزل للذاكرة وليست هوية مستخدم موثقة.

## الجلسات والترميز

العامل ثابت وله قفل خدمة وطابور تسلسلي ومجلد مستقل لكل UUID. النقل بأجزاء 2 MiB مع تحقق المصدر والنتيجة. بيئات الحزم معزولة حسب الأداة وتبقى داخل المورد؛ تُعاد الأوزان إلى ذاكرة العملية لكل مهمة، وإبقاء النموذج دافئًا في RAM تحسين لاحق.

لا يُستبدل L4 أو T4 بـA100 تلقائيًا. RAM ليست VRAM. الاختيار التلقائي يبحث عن ملف مؤهل لنفس البطاقة. NVENC لا يعمل لمجرد وجود GPU: الاختبار الفعلي شرط، وCPU بديل لترميز الفيديو عند الحاجة. A100/H100 لا يعنيان توفر NVENC.

عند رفض إنشاء الجلسة بسبب حد الجلسات صراحةً، يختار المستخدم السؤال أو إغلاق جلسة مدار مثبتة الخمول فقط؛ الجلسة النشطة أو المجهولة لا تُغلق تلقائيًا. إيقاف الانتظار لا يعني حذف جلسة Google.

## النشر

اربط GitHub بمشروع Netlify، أو انشر بعد المراجعة:
~~~bash
npm install
npm run build
npx netlify-cli@27.19.0 login
npx netlify-cli@27.19.0 link
npx netlify-cli@27.19.0 deploy --prod --no-build --skip-functions-cache --dir dist --functions netlify/functions
~~~

انشر من مجلد مصدر الدوال netlify/functions، لا من ZIP مبني وحده؛ /api/* يحتاج بيانات التغليف الحديثة. رؤوس dist/_headers تخص الثابت، والدالة تُعيد رؤوسها بنفسها. حد الطلبات 600 في 60 ثانية لكل IP ونطاق، وهو تحصين وليس ضمانًا ضد كل الإغراق.

## التحقق

GitHub Actions يبني المصدر ويفحص JavaScript/Python، واختبارات صلاحيات بتصاريح اصطناعية، وFFmpeg وFFmpeg.wasm فعليين، ثم يرفع المصدر والناتج كأثر قابل للتنزيل.

اجتياز CI لا يثبت نجاح OAuth/GPU الحقيقي أو جودة الفصل والترجمة والتوليد. اختبر حسابي Google مختلفين ومحاولات رفض قراءة وتنزيل وإغلاق مورد الحساب الآخر. لا ترسل كلمات مرور أو رموز وصول في المحادثة أو Issues.

## حدود واضحة

- المساعد الحالي يوجه إلى الأداة بقواعد عربية؛ ليس وكيل AI ينفذ أوامر مركبة داخل الدردشة.
- OCR يستخدم Tesseract وليس Google OCR. التطابق الكامل لتخطيط PDF إلى Word غير مضمون.
- فصل الموسيقى محليًا غير منفذ؛ حذف الصوت كله أداة مختلفة ومسمّاة بوضوح.
- تنزيل النماذج وذاكرة GPU والحزم والتوافق تحتاج اختبارًا حيًا بعد إعداد Google.
- فحص المحتوى لا يُعطل ولا يعاد التوليد تلقائيًا للتحايل عليه. رفض إطار لا يثبت أن الوصف غير مناسب.
- تنزيل المنصات لا يتجاوز تسجيل الدخول أو تحقق المنصة أو DRM.
- لا توجد مزامنة دائمة للملفات والنتائج في حساب مدار؛ احفظها قبل إغلاق الصفحة.

راجع SECURITY.md وAGENTS.md. تراخيص المكتبات والخطوط والنماذج مستقلة، ومنها قيود NLLB على الاستخدام؛ راجعها قبل الاستخدام التجاري. الكود المخصص ملك لصاحب المشروع ولم يُفرض عليه ترخيص إعادة توزيع عام.
